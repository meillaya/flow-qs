# Documentation index

This directory holds the human-facing documentation for flow-qs.

## Guides

- [ARCHITECTURE.md](./ARCHITECTURE.md): request, telemetry, and alert paths,
  service responsibilities, signal schema, SLO strategy, and chaos and load
  testing.
- [RUNBOOK.md](./RUNBOOK.md): response playbooks and cookbooks for adding a
  service, SLO, or chaos experiment.
- [DEMO.md](./DEMO.md): how `make demo` works and how to read its artifacts.
- [SETUP.md](./SETUP.md): prerequisites, development shell, cluster
  provisioning, and verification steps.
- [DRAWINGS.md](./DRAWINGS.md): how to regenerate and inspect the architecture
  figures.
